Non-Linear Mapper Oz-Co2版
（English: see the second half of this file / 英語の説明はこのファイルの後半にあります）
NonLinearMapper.exe をダブルクリックで起動（_internalとセット・書き込める場所へ）。
初回に SmartScreen 警告が出たら「詳細情報」→「実行」。Windows 10/11 対応。
.nlmf をダブルクリックするとその譜面が開いた状態で起動します。
ウィンドウのタイトルと画面右上に版番号（例: v1.4.0-oz）が表示されます。

▼アップデート（v1.3.0以降）
起動時に新しいバージョンが出ていれば更新内容が表示されます。「更新する」を選ぶと
ダウンロード後にアプリが再起動して更新されます（ファイルメニューの「更新を確認…」からも確認できます）。
config・asset・lang・plugins はそのまま残ります。入れ替える前の版は _previous_<版> フォルダに1世代だけ残ります
（新しい版で問題があった時は、その中の NonLinearMapper.exe と _internal を元の場所へ戻すと前の版に戻せます）。
起動時の確認は環境設定でOFFにできます。

▼旧バージョンからの手動アップデート手順（v1.2.0以前から更新する時・自動で更新できない時）
環境設定は configフォルダ、「アセットへ保存」したクリップ（ノーツ・ライトの配置パターン）は assetフォルダ に、
exe と同じ場所にあるフォルダへ保存されています。
プロジェクト（.nlmf）は各自が保存した場所にあるので影響しません。
 1. アプリを閉じ、今使っているフォルダをまるごとコピーしてバックアップしておく
 2. 新しいzipを「今のフォルダとは別の場所」に展開する（上書き展開はしない）
 3. 古いフォルダの config と asset を、新しいフォルダ（exeと同じ場所）へコピーする
    （lang は翻訳を自分で編集した場合のみコピー）
 4. 新しい NonLinearMapper.exe を起動し、版番号（タイトル・画面右上）が新しくなっていることを確認
 5. 問題なければ古いフォルダは削除して構いません
※v1.1.0以前から更新した場合: 既存プロジェクトの書き出し先フォルダは、最初の1回だけ
  INFO画面の書き出しノードの「出力フォルダ/カバー画像を再接続」で選び直してください
  （安全のため、このPCで選んだことのあるフォルダだけに書き出す仕組みにしました）。

▼起動時に "Failed to resolve Python.Runtime.Loader.Initialize ..." と出る場合
ダウンロードしたzipの中身が「インターネットから来たファイル」としてブロックされ、
DLLの読み込みに失敗することがあります。通常は自動で回避されますが、直らない場合は
zipファイルを右クリック→プロパティ→「許可する」にチェック→再度展開してください。

▼song.eggへの書き出し（変換）には ffmpeg が必要です
自動ではインストールされません。事前に以下を実行して導入してください。
  winget install Gyan.FFmpeg
未導入のまま書き出すと、エラーメッセージでインストール方法が案内されます。
NLMを起動したまま導入した場合は、NLMを一度閉じて起動し直してください。

※大切なデータはバックアップの上でご利用ください。

Non-Linear Mapper (Oz-Co2 edition) — English

Double-click NonLinearMapper.exe to start (keep it together with the _internal folder, in a place you can write to).
If SmartScreen warns on the first launch, click "More info" → "Run anyway". Windows 10/11.
Double-clicking a .nlmf file starts NLM with that map open.
The version number (e.g. v1.4.0-oz) is shown in the window title and at the top right of the screen.

* Switching the UI to English
The UI starts in Japanese. Click 環境設定 (Preferences — the second menu at the top left, next to ファイル)
and set 言語 / Language to English on the first tab. The setting is kept for the next launch.
Tutorials and the full README (English): https://github.com/Oz-Co-two/nlm-oz-co2/blob/master/README.en.md

* Updating (v1.3.0 or later)
When a new version is available, its changes are shown at startup. Choose "Update" and the app downloads it
and restarts to finish the update (you can also use "Check for updates…" in the File menu).
config, asset, lang and plugins are kept. The previous version is kept (one generation only) in the _previous_<version> folder
(if something goes wrong, copy NonLinearMapper.exe and _internal from that folder back to the original place).
The startup check can be turned off in Preferences.

* Updating manually (from v1.2.0 or earlier, or when the app cannot update itself)
Preferences are saved in the config folder and clips saved with "Save to assets" in the asset folder, next to the exe.
Projects (.nlmf) are saved wherever you chose, so they are not affected.
 1. Close the app and back up the folder you are using now (copy the whole folder)
 2. Extract the new zip to a different place from your current folder (do not extract it over the old one)
 3. Copy config and asset from the old folder to the new folder (next to the exe)
    (copy lang only if you edited a translation yourself)
 4. Start the new NonLinearMapper.exe and check that the version number (title / top right) is the new one
 5. If everything works, you can delete the old folder
* When updating from v1.1.0 or earlier: select the export folder of each existing project once again with
  "Reconnect output folder / cover image" on the export node of the INFO screen
  (for safety, NLM only writes to folders you have selected on this PC).

* If "Failed to resolve Python.Runtime.Loader.Initialize ..." appears at startup
Files extracted from a downloaded zip can be blocked as "downloaded from the internet", and loading a DLL fails.
NLM normally works around this automatically; if it still happens,
right-click the zip file → Properties → check "Unblock" → extract it again.

* Exporting song.egg (converting audio) needs ffmpeg
It is not installed automatically. Install it beforehand with:
  winget install Gyan.FFmpeg
If it is missing when you export, NLM shows how to install it.
If you install it while NLM is running, close NLM and start it again.

* Please back up important data before use.
